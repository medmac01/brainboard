How this works

brainboard holds your projects. Each project has its own items, decisions, thoughts and activity, stored as one JSON file on the server. This page, Claude, Codex and any other agent read and write the same files, so the board is the shared interface between you and them. Changes from anyone show up here within ~2 seconds.

Statuses. To do → Doing → Done. Use Needs decision when something is waiting on you to choose, Blocked when it's waiting on something else, and Won't fix to drop it (dropped items don't count against your %).

Experiments. Each project also has an Experiments tab for side runs (reruns, ablations, quick adjustments): the question, the setup, where it runs, the results and an outcome (Worked Inconclusive Didn't work). Link an experiment to the items it informs, and it shows up on those items too. Experiments don't count toward the % ring.

Voice input. The button next to a text box records you, and the transcript is added to that box. Click it again to stop, or press Esc to discard. Live recording needs the HTTPS address. Over plain HTTP the button lets you pick an audio file instead.

The % ring is priority-weighted: a P1 item counts 3×, P2 2×, P3 1×. Partial progress counts too, so move the slider as you go.

Talking to agents. Leave a note on an item (“Claude: draft the fix for this”) or drop a thought, then tell the agent “check the board”. It answers in the same note thread.

Shortcuts. / search · t new thought · g all projects · Esc close panel · ⌘↵ save a text box

Connect an agent

Install the brainboard skill into your agent harness from a clone of the repo:

./install-skill.sh claude      # ~/.claude/skills/brainboard
./install-skill.sh codex       # ~/.codex/skills/brainboard
./install-skill.sh agents      # ~/.agents/skills/brainboard (other harnesses)
./install-skill.sh --dir PATH  # anywhere else; --snippet prints an AGENTS.md block instead

Then point it at this server once with bb config --url . The agent can now do:

bb projects                       # list projects (* = current)
bb -p SLUG inbox                  # notes and thoughts waiting for the agent
bb -p SLUG next                   # what to work on
bb -p SLUG set E03 status=doing progress=40
bb -p SLUG note E03 "Changed …"
bb -p SLUG exp-add "Rerun with seed 7" --where host:~/runs --related E03
bb -p SLUG set X01 status=done outcome=worked results="…"
echo SLUG > .brainboard           # pin a repo to a project
