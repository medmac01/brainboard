How this works

Everything lives in one board file on the server (BRAINBOARD_DATA). This page, Claude, and any other agent all read and write that same board, so it's the shared interface. Changes from anyone show up here within ~2 seconds.

Statuses. To do → Doing → Done. Use Needs decision when something is waiting on you (or the prof) to choose, Blocked when it's waiting on something else, and Won't fix to drop it (dropped items don't count against your %).

The % ring is priority-weighted: a P1 item counts 3×, P2 2×, P3 1×. Partial progress counts too, so move the slider as you go.

Talking to Claude. Leave a note on an item (e.g. “Claude: draft the fix for this”) or drop a thought in the brain dump, then tell Claude “check the board”. Claude replies in the same note thread.

Shortcuts. / search · t new thought · Esc close panel · ⌘↵ save a text box

For agents (CLI)

python3 brainboard/cli.py summary
python3 brainboard/cli.py next                 # what to work on
python3 brainboard/cli.py list --status todo --priority P1
python3 brainboard/cli.py show E03
python3 brainboard/cli.py set E03 status=doing progress=40 owner=claude
python3 brainboard/cli.py note E03 "Changed C_Tac text in proposed_framework.tex:52"
python3 brainboard/cli.py thought "Question for the prof: …"
BRAINBOARD_WHO=codex python3 brainboard/cli.py …   # sign as another agent
